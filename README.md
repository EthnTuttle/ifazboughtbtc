# If Arizona Gov Bought Bitcoin

A simple landing page showing what would have happened if Arizona Governor had bought Bitcoin instead of vetoing SB1025.

## Features
- Real-time Bitcoin price updates using CoinGecko API
- Dark mode friendly design
- Responsive layout
- Auto-updates every 30 seconds

## Setup
1. Clone this repository
2. Replace the `X` in `index.html` with the actual Bitcoin amount
3. Make sure `veto.jpeg` is in the same directory as `index.html`

## Technologies Used
- HTML5
- CSS3
- JavaScript
- CoinGecko API
